# 🎯 SentimentScope — IMDB Movie Review Sentiment Analysis

## 📌 Project Overview
SentimentScope is a Natural Language Processing (NLP) project that analyzes movie reviews and predicts whether a review expresses positive or negative sentiment. The project applies text preprocessing, feature extraction, and machine learning techniques to build and evaluate a sentiment classification model. This project was built as part of an AI/ML learning program to demonstrate practical skills in NLP and model development.

## 🧠 Objectives
- Clean and preprocess raw text data
- Convert text into numerical features using NLP techniques
- Train machine learning models for sentiment classification
- Evaluate model performance using standard metrics

## 📁 Dataset
This project uses the IMDB Movie Reviews Dataset (aclImdb v1). Due to GitHub size limits, the dataset is not included in this repository. Required dataset folder:
```
aclImdb_v1/
```
Place the dataset in the root project folder before running the notebook.

## 🛠️ Technologies Used
Python, Jupyter Notebook, NumPy, Pandas, Scikit-learn, and NLTK.

## 📊 Model Workflow
The workflow includes text cleaning and normalization, tokenization, stop-word removal, feature extraction using Bag-of-Words or TF-IDF, model training, and model evaluation.

## ✅ Results
The trained model successfully classifies IMDB reviews as either positive or negative with strong performance.

## 🚀 Future Improvements
Future work includes using deep learning models such as LSTM and BERT, building a web application interface, and enabling real-time sentiment prediction.
